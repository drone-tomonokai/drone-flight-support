# 飛行日誌 — お問い合わせ窓口

ドローン飛行日誌アプリ「飛行日誌」に関するお問い合わせ用のリポジトリです。
アプリのソースコードはここにはありません。

## お問い合わせ方法

[Issues](https://github.com/drone-tomonokai/drone-flight-support/issues) から新しいIssueを作成してください。

- 不具合の報告
- 機能の要望
- プライバシーポリシーに関するご質問
- その他のご質問

不具合の報告では、次の情報があると調査が早くなります。

- アプリのバージョン（設定画面に表示されています）
- 端末の機種とAndroidのバージョン
- 操作の手順と、起きたこと・期待していたこと

## ご注意

Issueは**誰でも閲覧できる公開の場**です。次の情報は書き込まないでください。

- 氏名・住所・電話番号・メールアドレスなどの個人情報
- 飛行記録の内容（飛行場所・日時・機体の登録記号など）
- 技能証明書番号などの資格情報
- バックアップファイルや、個人情報が写ったスクリーンショット
